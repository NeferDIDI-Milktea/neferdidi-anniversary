# Neferdidi — Two Years Together

موقع احتفالي تفاعلي لذكرى Neferdidi السنوية الثانية، يدعم تصوير صورة أو تسجيل فيديو من كاميرا الجهاز، أو رفع ملف من المعرض، وإرسال المشاركات إلى لوحة تحكم خاصة بالبراند.

## المميزات

- مقدمة احتفالية سينمائية متحركة قابلة للتخطي.
- تصميم عربي متجاوب مع الموبايل والكمبيوتر بألوان تركواز وذهبي.
- تشغيل كاميرا أمامية أو خلفية داخل الموقع (حسب دعم الجهاز والمتصفح).
- تصوير صورة أو تسجيل فيديو حتى 30 ثانية.
- رفع صورة أو فيديو من معرض الجهاز، بحد أقصى افتراضي 100MB.
- نموذج الاسم والفرع ورسالة اختيارية.
- موافقة مطلوبة على إرسال المشاركة، وموافقة منفصلة واختيارية على الاستخدام التسويقي.
- لوحة إدارة بكلمة مرور، بحث، فلترة حسب الموافقة التسويقية، معاينة، تنزيل، وحذف.
- الملفات الخاصة محفوظة خارج مجلد الواجهة العامة، ولا تُعرض للزوار.

## تشغيله على جهازك

**أسهل طريقة على Windows:** بعد تثبيت Node.js 18 أو أحدث وفك الضغط، افتح `start-windows.bat` واكتب كلمة مرور لوحة الإدارة. هيشتغل الموقع على `http://localhost:3000`، ولوحة التحكم على `http://localhost:3000/admin`. سيب نافذة التشغيل مفتوحة أثناء الاختبار.

**التشغيل اليدوي:**

1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط المشروع وافتح مجلد `neferdidi-anniversary` في Terminal أو PowerShell. لا يحتاج المشروع إلى `npm install`؛ فهو يستخدم وحدات Node.js المدمجة فقط.
3. عيّن كلمة مرور الإدارة قبل تشغيل الموقع.

   **Windows PowerShell:**

   ```powershell
   $env:ADMIN_PASSWORD="اكتب-كلمة-مرور-طويلة-وفريدة-هنا"
   $env:PORT="3000"
   npm start
   ```

   **macOS / Linux:**

   ```bash
   export ADMIN_PASSWORD="اكتب-كلمة-مرور-طويلة-وفريدة-هنا"
   export PORT=3000
   npm start
   ```

5. افتح `http://localhost:3000` لمعاينة الموقع، و`http://localhost:3000/admin` للوحة التحكم. استخدم كلمة المرور التي عيّنتها.

> **مهم:** الكاميرا تعمل على localhost أثناء التطوير، وعلى رابط HTTPS بعد النشر. فتح ملف HTML مباشرةً بالنقر عليه لن يشغّل واجهة الإرسال؛ شغّل السيرفر بالأوامر أعلاه.

## النشر على الإنترنت

هذا المشروع يحتاج استضافة Node.js تدعم تشغيل سيرفر دائم وكتابة الملفات، أو تخزين ملفات دائم مُعدّ بشكل منفصل. لا توجد حزم خارجية مطلوب تثبيتها. قبل نشره:

1. ارفع ملفات المشروع إلى استضافة Node.js.
2. أضف متغير البيئة `ADMIN_PASSWORD` بكلمة مرور فريدة طويلة، ولا تستخدم كلمة المرور التجريبية.
3. اجعل `PORT` يطابق المنفذ الذي تحدده الاستضافة، واستخدم HTTPS بنطاقك.
4. تأكد أن مجلدي `uploads` و`data` على مساحة تخزين دائمة لا تُمسح مع إعادة التشغيل أو إعادة النشر.
5. اضبط حد رفع الملفات على الاستضافة والـ reverse proxy ليتوافق مع `MAX_UPLOAD_MB`.
6. اختبر إرسال صورة وفيديو من موبايل حقيقي، ثم سجل دخول لوحة الإدارة للتأكد أن الملفات وصلت.
7. اعمل نسخة احتياطية آمنة من `data/submissions.json` ومجلد `uploads`، وحدد مدة الاحتفاظ بالمشاركات ومن يحق له الاطلاع عليها.

مثال لمتغيرات البيئة:

```text
ADMIN_PASSWORD=كلمة-مرور-فريدة-وطويلة
PORT=3000
MAX_UPLOAD_MB=100
```

## أماكن حفظ الملفات

- `uploads/`: ملفات الصور والفيديو الأصلية، وليست متاحة مباشرةً للعامة.
- `data/submissions.json`: بيانات المشاركات والموافقات.
- `public/`: واجهة العملاء وواجهة لوحة الإدارة.

## اعتبارات قبل إطلاق الحملة

- التصميم الحالي يستخدم معالجة رسومية وأشكالًا متحركة داخل CSS؛ المقدمة ليست ملف فيديو إنتاجيًا مستقلًا. يمكن استبدالها بفيديو البراند النهائي لاحقًا.
- أسماء الفروع الحالية أمثلة أولية (`Almaza Park` و`Sol App` وغيرها)، عدّلها حسب الفروع الفعلية قبل الإطلاق.
- الملفات تُحفظ على مساحة السيرفر؛ ضغط الفيديوهات، التخزين السحابي، الإشعارات البريدية، ونسخ احتياطي مجدول غير مفعّلة تلقائيًا في النسخة الحالية.
- لا تنشر أي مادة دون وجود موافقة صريحة مناسبة، واحتفظ بالموافقات مع الملف.
- كلمة المرور الاحتياطية الموجودة في الكود للتطوير المحلي فقط. عيّن `ADMIN_PASSWORD` آمنًا دائمًا قبل تعريض الموقع للإنترنت.
